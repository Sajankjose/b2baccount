GEOJIT B2B PARTNER LANDING PAGE

Files
- index.html : ready-to-host single page

Quick customisation
1. Partner name:
   Add ?partner=Federal%20Bank to the URL, or edit "In association with your bank" in index.html.

2. Partner-specific account-opening link:
   Preferred: replace https://hello.geojit.com/ in the JavaScript section at the bottom.
   Or use a URL parameter:
   ?openAccountUrl=https%3A%2F%2Fyour-partner-onboarding-url

3. Geojit logo / Flip screenshots:
   The page currently loads public web assets. For production, if your hosting/security policy requires local assets, replace the image URLs with approved Geojit-hosted/local files.

4. Tracking:
   Add your MoEngage / analytics tracking to CTA clicks if required.

Design intent
- Minimal B2B partner journey
- Geojit-first branding with room for partner identification
- Strong account-opening CTA
- Compact benefits + Flip section
- Fully responsive with mobile sticky CTA
- No framework or build process required
